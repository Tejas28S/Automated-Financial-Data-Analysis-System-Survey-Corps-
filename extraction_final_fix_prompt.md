### 2.1 Zero-row adjudicator (fixes the 4 false zeros, prevents future false zeros)

A file may only be finalized as zero-row if BOTH are true:
1. The document is readable (text layer present, or OCR succeeded), AND
2. Either: explicit zero-activity evidence exists in the text (e.g. "No Transactions in this Period", statement summary showing 0 withdrawals + 0 deposits), OR raw-text/table telemetry shows genuinely zero date+money row patterns after trying every fallback in 2.2.

If a file currently returns 0 rows and does NOT meet this bar, it is a **functional extraction failure**, not a valid zero-row result. Log it as `status: functional_failure`, not `status: ok`. This is a new status value — `files_failed: 0` must no longer silently absorb these.

```python
def adjudicate_zero_row(file_path: str, raw_text: str, telemetry: dict) -> dict:
    """
    Returns {"is_true_zero": bool, "reason": str, "status": "ok"|"functional_failure"}
    Never returns is_true_zero=True without a positive reason string.
    """
    ZERO_ACTIVITY_PATTERNS = [
        r'no transactions?\s+(?:in|for|during)\s+this\s+period',
        r'nil\s+transactions?',
        r'(?:total\s+)?withdrawals?\s*:?\s*0\b.*deposits?\s*:?\s*0\b',
        r'(?:total\s+)?deposits?\s*:?\s*0\b.*withdrawals?\s*:?\s*0\b',
    ]
    for pat in ZERO_ACTIVITY_PATTERNS:
        if re.search(pat, raw_text, re.IGNORECASE | re.DOTALL):
            return {"is_true_zero": True, "reason": f"explicit_zero_activity_text:{pat}", "status": "ok"}

    if telemetry.get('date_money_lines_found', 0) == 0 and telemetry.get('tables_detected', 0) == 0:
        # Confirm every fallback in 2.2 was actually attempted before trusting this
        if telemetry.get('fallback_chain_exhausted', False):
            return {"is_true_zero": True, "reason": "no_transaction_structure_after_full_fallback_chain", "status": "ok"}

    return {"is_true_zero": False, "reason": "non_empty_evidence_present_but_zero_rows_extracted", "status": "functional_failure"}
```

**Wire this in before the final zero-row decision is written to output. Run it now on the 6 currently-reported zero-row files and print the verdict for each.**

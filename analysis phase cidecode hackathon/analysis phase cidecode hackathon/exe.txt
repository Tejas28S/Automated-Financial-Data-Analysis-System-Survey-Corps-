1. CORE BACKEND PIPELINE (CLI ENGINE)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The backend analysis engine is executed using Python. The main entry point is the 
reproducible command-line tool `analysis_engine/cli.py`.

Execution Command:
  python -m analysis_engine.cli --input <CSV_FILE> --output-dir <OUTPUT_DIR>

Optional Flags:
  --no-llm           Disable optional LLM counterparty resolution (default).
  --trace-credits    Specify credit transaction IDs to trace for money trails (Pattern 10).
  --verbose, -v      Enable detailed debug logging to stdout.

Example (Run Single Case):
  python -m analysis_engine.cli --input synthetic_data/pattern_01_round_trip/rt_case_01.csv --output-dir outputs/rt_case_01 --no-llm

Generated Output Files:
  1. SQLite database:    outputs/<case_name>/analysis.db
  2. Raw results JSON:   outputs/<case_name>/analysis_results.json
  3. Rich Report JSON:   analysis_op/<case_name>/report.json

2. RUN ASSISTANT (NATIVE DESKTOP DRAG & DROP APP)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

To open the interactive Drag & Drop desktop window, execute:
  python run_all_csvs.py

Features:
  • Drag & Drop: Drag any CSV file directly into the application window to analyze it instantly.
  • In-App Console: See standard logs and patterns compiled in real-time.
  • File outputs: Creates `outputs/<case_name>/analysis.db` and copies `outputs/<case_name>/report.json` directly into that folder.
  • Direct Actions: Pop open the outputs directory in Windows Explorer using the action buttons upon completion.
